What is 3n - 1?

The 3n - 1 sequence is a variant of the famous Collatz conjecture. Starting from any positive integer n:

if n is even: n → n/2
if n is odd: n → 3n - 1

Unlike the original 3n+1 (still unproven), the 3n-1 variant has been completely solved. Every number eventually falls into one of three cycles.
